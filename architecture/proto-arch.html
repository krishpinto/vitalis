USER — DOCTOR ( starts consult · same phone/laptop capture as today )
APP CAPTURE ( mic on-device · audio goes out in bits and pieces, not one blob )
VAD / SILENCE TRIM ( drops dead air before it's ever billed as audio minutes )
CHUNKED STT ( Sarvam Saaras, current vendor · live chunks + a diarization batch pass on stop · ₹30/hr + ₹45/hr )
GEMINI — STRUCTURING + LIVE CARDS ( proforma + suggestion cards pushed to the doctor's screen · context kept cumulatively — each call resends the transcript-so-far )
OPEN COST LEVER ( cumulative context ≈ 1.5× every other stage combined · fix: Gemini context caching, or a sliding window instead of full history )
WEIGHTS ENGINE ( friend's own model · called via a paid LLM API · vendor + pricing still TBD, modeled at Flash-tier parity for now )
GEMINI ENGINE — TIERED DD ( same shape as today's Call #2 · grounded against the verified RAG corpus, not just the transcript )
RAG CORPUS ( <50 verified guideline / research docs · one-time indexing, effectively free · this is where "accurate" is enforced )
FINAL ARBITER — GEMINI ( one more Gemini call · takes both engines' outputs, value-weighs them, picks/synthesizes the more likely one — defaults to the Gemini engine when it's a toss-up )
DOCTOR UI ( live cards during the consult · arbitrated differential after · doctor is still the final call, every time )
TESTING PRODUCT ONLY ( explicitly not used for real diagnosis at this stage — framed to doctors as a draft to react to )
COST MODEL — 15 MIN CONSULT, GEMINI 2.5 FLASH + SARVAM SAARAS ( JUL 2026 PRICING )
STT live + diarization ₹15.0 (~$0.18) live cards (36 calls) ~$0.028 weights engine ~$0.004 gemini engine ~$0.004 final arbiter ~$0.001 TOTAL ≈ $0.22 / consult (₹18.3)
STT is ~82% of per-consult spend, not LLM tokens. At 20 doctors × 10 consults/day: ≈ $44/day (₹3,624) · ≈ $1,310/month (₹108,720). Cost scales with consult volume, not concurrency.
