TEMPLATE REGISTRY ( chest pain → cardiac · abdo pain → GI · the ADAPTIVE proforma )

PROFORMA STATE ( live structured fields · every field stores its transcript span + timestamp = provenance )
SWAP PATH ( doc §5 ) ( LLM: Gemini API → self-hosted MedGemma / Meditron on vLLM → on-device quantized · STT: managed API → self-hosted Indic ASR + diarization on our Mumbai servers · same schemas — endpoints are config )
SEVERITY CONSTANTS ( fixed clinical multipliers · HEART-score lineage · versioned in DB · NEVER invented by the LLM )
SCORING ENGINE — deterministic ( rank = feature_match × severity_multiplier, normalized · weighted sum, not raw count · <50ms, zero model calls · DXplain lineage, running since 1987 )
RED-FLAG SCREEN ( killers ALWAYS evaluated · thin evidence → "insufficient_data", shown flagged — never silently dropped )
RAG CITATION LAYER ( pgvector over SNOMED CT · ICD-10 · StatPearls · WHO / ICMR STGs · every differential carries a citation · KB = licensing + ingestion, not authorship )
DDx PAYLOAD ( ranked differentials + supporting AND contradicting fields + missing_fields_that_would_help + red-flag statuses )
DOCTOR UI ( glanceable side panel · proforma fills quietly · DDx list pin / dismiss · gap prompts: "onset not asked yet" · ≤6s utterance → screen · doctor-only, nothing auto-inserted into the record )
POST-CONSULT JOB ( async via pg-boss: final structured summary + note )
EMR PUSH ADAPTER ( FHIR-shaped bundle · we are a LAYER, not the EMR )
EXISTING EMR / HMS ( demo targets: OpenMRS / Bahmni — open source, zero partnerships needed · ABDM-aligned )
